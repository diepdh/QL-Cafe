# Mobile Performance Workflow

Workspace con này dùng để áp dụng workflow Vibecode vào bài toán tối ưu hiệu năng mobile cho `QuanLyCF`.

Cấu trúc chính:
- `.aiwf/input/goal.md`: mục tiêu đầu bài cho Phase A
- `.aiwf/input/plan.md`: kế hoạch do Brain chuẩn bị
- `.aiwf/run/logs/`: nơi orchestrator sẽ ghi log ở các bước sau

Workspace gốc của ứng dụng vẫn là `QuanLyCF`. Workspace này chỉ phục vụ điều phối workflow và chuẩn bị tài liệu đầu vào.
